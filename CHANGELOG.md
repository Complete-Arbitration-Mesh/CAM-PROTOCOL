# Changelog since v0.2.0

## v1.0.0 (2025-05-17)

### Major Changes

- **Repository Restructuring**: Complete restructuring of the repository according to the new tiered organization
  - Organized into Core, Professional, and Enterprise tiers
  - Added clear separation of components with appropriate licensing
  - Updated directory structure for better organization and maintainability

- **Documentation Updates**:
  - Added comprehensive protocol documentation
  - Added architecture documentation
  - Added guides for quickstart, monitoring, policies, and FAQs
  - Added API reference documentation

- **SDK Development**:
  - Created JavaScript/TypeScript SDK with type definitions
  - Created Python SDK with full client implementation
  - Added example implementations and provider integrations

- **Infrastructure Updates**:
  - Added deployment configurations for Kubernetes, Docker, Terraform, and serverless platforms
  - Updated GitHub workflow configurations for CI/CD

### Migration Notes

Migration from v0.2.0 to v1.0.0 requires updating import statements and adapting to the new API structure. Please refer to the migration guide for detailed instructions.
