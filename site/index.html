MCP executes tool calls with zero native governance

Model Context Protocol connects AI agents to databases, APIs, and infrastructure. Every tool call is a production-impacting operation. The spec provides no audit trail, no access control, and no rate limiting — that gap is already being exploited.

!

Supabase / Cursor prompt injection

Attackers embedded prompt injection instructions inside Supabase support tickets. Cursor's MCP integration executed the injected instructions and exfiltrated integration tokens — a real breach, documented publicly in early 2025.

!

GitHub MCP private repo exfiltration

Researchers demonstrated that malicious instructions in public GitHub issue bodies caused MCP-connected agents to read and exfiltrate content from private repositories the user had authorized. No jailbreak required — just a crafted issue.

No Audit Trail

Your SOC 2 auditor asks "show me every tool call an AI agent made against customer data last quarter." With bare MCP, you have nothing.

No Policy Engine

Every MCP server accepts every call from every agent. No trust tiers, no tool-level allow/deny rules, no data classification gates.

No Rate Limiting

A runaway agent can hammer your production API with unlimited tool calls. No circuit breakers. No per-tenant backpressure. No cost control.

No Access Control

One unguarded kubectl delete from an AI agent is a production outage. MCP has no capability-based trust model.

Up and running in 5 minutes

Community edition works out of the box — no license key, no sign-up.

gateway.ts 
// 1. Install
// npm install @cam-protocol/complete-arbitration-mesh

import { MCPGateway } from '@cam-protocol/complete-arbitration-mesh/mcp';

// 2. Configure the gateway with your MCP servers and policies
const gateway = new MCPGateway({
  servers: [
    { id: 'db', name: 'database', transport: 'stdio', command: 'mcp-server-db', trustTier: 'trusted', enabled: true },
    { id: 'web', name: 'websearch', transport: 'sse', endpoint: 'http://localhost:3001', trustTier: 'standard', enabled: true },
  ],
  policies: [{
    id: 'no-pii-external', name: 'Block PII to external tools', priority: 100, enabled: true,
    conditions: [{ field: 'tool.dataClassifications', operator: 'contains', value: 'pii' }],
    actions: ['deny'],
  }],
  defaults: { timeout: 30000, maxRetries: 3, retryDelayMs: 1000, defaultTrustTier: 'standard' },
  audit: { enabled: true, retentionDays: 30, includeArguments: true },
});

await gateway.initialize();

// 3. Every tool call is now policy-enforced, rate-limited, and audit-logged
const result = await gateway.callTool({ toolName: 'search', arguments: { query: '...' }, tenantId: 'my-app' });
console.log(result.traceId);   // Audit trace
console.log(result.serverId);  // Which MCP server handled it
